# 🧠 CogniSketch AI — Voice-Driven Neural Synthesis Workspace

CogniSketch AI is an advanced, multi-modal speech-to-image application that bridges real-time hardware voice capture pipelines with deep learning neural synthesis engines. Built using a streamlined, zero-void dynamic UI architecture, the application allows users to transcribe continuous spoken creative commands, map them to precise descriptive prompts, and synthesize stunning high-resolution artwork entirely hands-free.

---

## 🚀 Key Features

- **🎙️ Direct Hardware Voice Hub:** Seamlessly captures microphone audio streams and utilizes intelligent speech recognition parameters to convert speech into structured text.
- **⚡ Zero-Void Layout Architecture:** Custom responsive CSS grid implementation built on top of Streamlit that eliminates empty vertical spatial containers, ensuring text elements, live analytics, and image canvases sit completely flush.
- **🎨 Global Preset Matrix:** Pre-configured optimization prompts mapped for 1/7 scale figurine photography aesthetics, detailed traditional Indian folk art configurations, and high-contrast editorial cinematic film looks.
- **📊 Live Production Telemetry:** Embedded analytics sub-hud displaying system status updates, targeted neural networks, frame matrix sizing (1024x1024px), and latency monitoring.
- **📥 One-Click Production Export:** Immediate high-resolution master asset rendering and PNG extraction layout pipeline.

---

## 🛠️ Architecture & Tech Stack

- **Frontend Interface:** Streamlit (Custom HTML/CSS Injection Layer)
- **Speech Processing Engine:** SpeechRecognition Python Core Library
- **Neural Network Backbone:** Stability AI Diffusion Network Core API
- **Image Processing Asset Array:** Pillow (PIL) & BytesIO Buffering
